图形构成

中心为阴阳鱼，四周分布四个圆环（上、下、左、右），外缘以大圆描边收束。

  • 上下圆环两层叠放，黑白互补
  • 左右圆环三层叠放，内外嵌套
参数说明

全局控制

  • 暂停 / 继续 冻结整个动画时钟
  • 重置全部 恢复所有参数为初始值
  • 启用整体 控制整体是否绕中心旋转
  • 转速 旋转角速度，单位 度/秒，负值反向

独立元素

  • 变速 圆环演化速率，单位 循环/秒；负值反向，数值越大演化越快
  • 转速（阴阳鱼）鱼身自转角速度，单位 度/秒
  • 鱼眼 显示/隐藏阴阳鱼中心两个小圆
  • 边线 显示/隐藏阴阳鱼外圆描边
演化原理

每个圆环内部维护一个 phase ∈ [0, 1) 的循环相位：

  • phase 0 → 0.5：正向演化，从本侧默认态过渡到对侧形态
  • phase 0.5 → 1：反向演化，从对侧形态回到本侧默认态
  • phase = 1 视觉等同于 phase = 0，循环闭合无跳跃

四层圆环的演化互相独立，叠加后形成丰富的视觉节奏。
