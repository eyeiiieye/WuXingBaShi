眼师五行八识图演示工具

以Canvas实时绘制的可视化图形演示工具，支持多种图示元素显示，所有功能参数可实时调节并写入本地缓存。

图形构成
  • 五行八识图：中心阴阳鱼+上下左右四环，（上/下两层、左/右三层），外缘大圆描边
  • 阴阳管道图：正反词过圆心对称，衬阴阳鱼底图与刻度
  • 田字格：口字框 + 十字 + 撇捺，均可独立旋转；中心可显示单个文字
  • 方圆图：六十四卦方圆图圆图环绕大圆外侧、方图占据田字格区域；支持自定义卦序
  • 八卦图：中心阴阳鱼，向外依次为五行、内卦、外卦、天干、地支、节气
  • 河图：围棋点阵河图显示，可选显示辅助线
  • 洛书：方形点阵，可叠加 19 路围棋线
  • 围棋：支持黑 / 白 / 交替落子、撤销与清空
  • 画板：独立画板，支持自由线 / 直线 / 方 / 圆 / 橡皮擦等功能
常用操作
  • 暂停 / 重置 冻结时钟或恢复全部默认
  • 转速 / 变速 正负值控制方向与快慢，滑杆右侧 − / + 步进微调
  • 角度行 实时角度，左旋 / 右旋每击 ±1°
  • 边线 / 虚线 / 鱼眼 / 翻转 控制中心阴阳鱼与四环的外观细节
  • 导出 PNG 主画布包含河图 / 洛书 / 围棋 / 画板笔迹
演化原理

四环内部各有 phase ∈ [0, 1) 循环相位：0 → 0.5 正向演化、0.5 → 1 反向演化，在默认态与对侧形态之间平滑过渡。四层独立叠加，形成丰富节奏。
